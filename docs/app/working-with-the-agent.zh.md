# 怎么跟助手配合

右边这个助手，不是在笔记应用上挂了个聊天框。它对你的文件夹有真实的读写权限：能读
文件、搜索、写新文件、按你的要求重新整理、读 PDF，也能改应用自己的设置。

## 让它做事

用大白话说就行。举几个例子，看看范围有多大：

- 「我以前写过关于注意力机制的什么内容？」
- 「把这篇 PDF 归到该去的地方，再帮我写一页摘要。」
- 「把这次对话整理成一篇笔记。」
- 「装上文献检索的工具，这样你就能查论文了。」
- 「把写入模式改成每次都问我。」
- 「这个应用的 API key 是怎么管理的？」

两个小技巧：**@** 用来指定某个文件，**/** 用来直接调用一个存好的工作流。

它会用你说话的语言来回答——思考过程也一样——你换语言它就跟着换。设置 → 通用里的界面
语言只是兜底：当一条消息（比如只有一个路径、或者只拖进来一个文件）没法判断时才用它。

## 修改是立刻生效还是先问你

**设置 → Agent → 写入模式** 有两个选项：

- **直接写入（事后审阅）** —— 默认。改动立即生效，每个被改动的文件都会列出来，你
  可以事后确认或撤销。
- **先询问** —— 每一次写入、修改、删除都会让对话停在一张卡片上，就在聊天里：文件
  名、改动对照、「批准 / 拒绝」两个按钮。你不点，助手就一直等 —— 没有会错过的弹窗，
  哪个对话提的改动就在哪个对话里问你。

不管选哪个，**删除文件夹或二进制文件永远都会先问你**，因为这两样找不回来。提交 git
也永远是单独的、需要你明确开口的动作 —— 你不说，助手不会提交。

已经写进磁盘的改动收在左侧栏的 diff 图标后面，上面带一个数字。点开就能左右对照地
看改了什么，逐个保留或撤销。

如果你拒绝了某个改动，它会问你想要什么，而不是换个姿势再试一遍。卡片还等着的时候
按了停止，不算拒绝 —— 什么都没写入，你接着聊它会把这个问题重新拾起来。

## 计划清单

只要事情有好几步，助手会维护一个可见的清单，你能随时看到它做到哪了、还剩什么。这个
不用你要求。清单属于它所在的对话，会随对话一起保存——关掉标签或刷新页面，回来时它
还在原处。只有点它的 × 才会把它清掉。

## 对话

每个对话各占一个标签页。在设置 → Agent 里打开多标签后，可以同时开好几个。

正在跑的对话，你切走或关掉它的标签它都会继续跑。只有按停止、删除对话、或者关掉整个
页面才会中断。

停止就是真的停：正在发出的请求也会一并取消，不只是停下回复，对话当场就收尾。少数事情
一旦开始就收不回来——已经发出去的推送、索引到一半的文档——它们会在后台跑完，但没有人
再等它们。

## 找回之前的对话

每个对话都会留下来，助手顶栏的列表图标就是它们的列表——最新的在上面，你正在看的那个
有标记。点一行就打开；星标把常用的对话留在手边，✕ 是删除。

旁边的 ⤢ 按钮（或者 **⇧⌘.**）把助手放大到整个窗口。这个模式下列表常驻在左边一栏，上面是「新对话」和
「搜索对话」——就是一个聊天应用的样子，适合对话本身就是正事、而不是文件旁边的帮手的
时候。设置和这份手册在那一栏的底部，因为左边的图标栏被盖住了。按 Esc 或那一栏顶部的
✕ 回到文件。

在这个模式下点助手提到的任何东西——文件、wikilink、引用的段落、引文——都会退出这个
模式并打开它指向的内容；键盘在这里照样能叫出搜索面板，从里面选一个文件也是一样。如果
那个文件已经不在了，就什么都不动，不会为了一片空白把窗口让出来。

## 换个说法重新问

一个回复跑偏了，你不用重开一次对话，也不用跟它掰扯。把鼠标移到你自己发的某条消息上，
点那支铅笔：这句话会回到输入框，你改完发出去，对话就从那里接着走。

被你放下的那个回复不会被扔掉。你这条消息现在有了多个版本 —— 旁边会出现一个小小的
**1/2**，左右箭头在它们之间切换。每个版本各自保留着它后面发生的一切，所以你可以试两条
路，再回到任何一条。

有两点要知道：

- 助手会从那个点重新回答一次，也就是要花一次回复的钱。
- **你的文件不会跟着回退。** 已经写下、移动或删除的东西原样留在那里。往回走改变的是
  对话，不是你的文件夹 —— 文件的修改请在差异面板里撤销，或者交给 git。

在这个功能出现之前就开始的对话里，早先那些消息没有铅笔 —— 当时的记录方式没法把它们一条
一条单独重放。从现在起你在里面说的每一句，都可以照常重新问。

## 把对话存下来

这是两件不同的事，区别很重要：

- **保存** 是把对话原样写成一个 Markdown 文件放进你的文件夹。说「把这次对话存下来」。
  你得到的是一份完整记录 —— 一个普通笔记。
- **提炼** 是把讨论里的**结论**抽出来，写进对应主题的页面，已经有合适的页面就合并
  进去。说「把这个整理成笔记」。

几周前存下来的对话也能提炼 —— 它就是个普通文件，报个名字让它去处理就行。

讨论真的得出结论时，助手可能会问一次要不要提炼。它不会自作主张。

## 让它看你打开的网页

装了 localmd Connect 之后（见 `tools`），**@** 里除了文件，还会列出你浏览器里打开
的标签页。选中一个，它就变成输入框上方的一枚 chip。想再加一个就再敲一次 **@**——
选上几个，助手就能拿它们做对比。chip 上的 ✕ 用来取消。

这些 chip 跟着你接下来发出的那条消息一起走，发完这一排就空了。这正是它们的意义所
在：一枚 chip 表示**这条**消息说的是那个页面，所以「总结下」总结的是你选的标签页，
而不是你编辑器里恰好开着的那个文件。追问时也不用重选——地址留在这段对话里。

跟着消息一起发出去的是标签页的地址，不是网页内容的副本：助手需要时自己去读，而且是
**那时候**读，不是你选中的时候。这个区别比听上去重要——它读到的是你眼前这一份：已
登录、带着你搜过筛过的状态，跟同一个网址给陌生人看的那一份并不是同一个页面。

## 它上不了网的时候

你不给它联网能力，它就没有 —— 而且它会直接告诉你，不会编一个答案出来。详见 `tools`。

它也不会引用一个自己没真正打开过的链接。如果某个说法靠的是它的常识而不是它读过的
页面，它会明说。

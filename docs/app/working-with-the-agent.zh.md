# 怎么跟助手配合

右边这个助手，不是在笔记应用上挂了个聊天框。它对你的文件夹有真实的读写权限：能读
文件、搜索、写新文件、按你的要求重新整理、读 PDF，也能改应用自己的设置。

## 让它做事

用大白话说就行。举几个例子，看看范围有多大：

- 「我以前写过关于注意力机制的什么内容？」
- 「把这篇 PDF 归到该去的地方，再帮我写一页摘要。」
- 「把这次对话整理成一篇笔记。」
- 「装上文献检索的工具，这样你就能查论文了。」
- 「把写入模式改成每次都问我。」
- 「这个应用的 API key 是怎么管理的？」

两个小技巧：**@** 用来指定某个文件，**/** 用来直接调用一个存好的工作流。

它会用你说话的语言来回答——思考过程也一样——你换语言它就跟着换。设置 → 通用里的界面
语言只是兜底：当一条消息（比如只有一个路径、或者只拖进来一个文件）没法判断时才用它。

## 修改是立刻生效还是先问你

**设置 → Agent → 写入模式** 有两个选项：

- **直接写入（事后审阅）** —— 默认。改动立即生效，每个被改动的文件都会列出来，你
  可以事后确认或撤销。
- **先询问** —— 每一次写入、修改、删除都会让对话停在一张卡片上，就在聊天里：文件
  名、改动对照、「批准 / 拒绝」两个按钮。你不点，助手就一直等 —— 没有会错过的弹窗，
  哪个对话提的改动就在哪个对话里问你。

不管选哪个，**删除文件夹或二进制文件永远都会先问你**，因为这两样找不回来。提交 git
也永远是单独的、需要你明确开口的动作 —— 你不说，助手不会提交。

已经写进磁盘的改动收在左侧栏的 diff 图标后面，上面带一个数字。点开就能左右对照地
看改了什么，逐个保留或撤销。

如果你拒绝了某个改动，它会问你想要什么，而不是换个姿势再试一遍。卡片还等着的时候
按了停止，不算拒绝 —— 什么都没写入，你接着聊它会把这个问题重新拾起来。

## 计划清单

只要事情有好几步，助手会维护一个可见的清单，你能随时看到它做到哪了、还剩什么。这个
不用你要求。

## 会话

每次对话是一个会话。在设置 → Agent 里打开多标签后，可以同时开好几个。

正在跑的会话，你切走或关掉它的标签它都会继续跑。只有按停止、删除会话、或者关掉整个
页面才会中断。

停止就是真的停：正在发出的请求也会一并取消，不只是停下回复，对话当场就收尾。少数事情
一旦开始就收不回来——已经发出去的推送、索引到一半的文档——它们会在后台跑完，但没有人
再等它们。

## 把对话存下来

这是两件不同的事，区别很重要：

- **保存** 是把对话原样写成一个 Markdown 文件放进你的文件夹。说「把这次对话存下来」。
  你得到的是一份完整记录 —— 一个普通笔记。
- **提炼** 是把讨论里的**结论**抽出来，写进对应主题的页面，已经有合适的页面就合并
  进去。说「把这个整理成笔记」。

几周前存下来的对话也能提炼 —— 它就是个普通文件，报个名字让它去处理就行。

讨论真的得出结论时，助手可能会问一次要不要提炼。它不会自作主张。

## 它上不了网的时候

你不给它联网能力，它就没有 —— 而且它会直接告诉你，不会编一个答案出来。详见 `tools`。

它也不会引用一个自己没真正打开过的链接。如果某个说法靠的是它的常识而不是它读过的
页面，它会明说。

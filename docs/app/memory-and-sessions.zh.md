# 跨对话的记忆

每次对话都是从零开始的。唯一能带过去的是一个文件：文件夹根目录下的 **`MEMORY.md`**。

这个文件存在的话，助手每次对话开始都会读它，并且照着办。典型内容比如：

- 你喜欢东西怎么写、怎么归置
- 你当前在做什么
- 一些你不想反复解释的决定

## 只有你开口它才会写

助手不会自己往记忆里加东西，也不会偷偷把一次对话总结进去。你说「记住……」或者
「忘掉……」，它才会去改这个文件，并且保留里面已有的内容。

这是有意设的限制。会自己长大的记忆，最后会变成一个没人信也没人看的文件。

## 保持简短

这个文件是**整个塞进每一次请求**的，所以每条消息都在为它付费。十来行短句是好记忆，
三页纸是负担。

如果它变长了，让助手帮你精简一下。

## 你随时可以直接看

它就是你文件夹里一个普通的 Markdown 文件。打开、编辑、删掉某一行、放进 git 都行。
没有任何藏在别处的隐藏状态。

## 记忆、skill、笔记的区别

三个容易混的东西：

- **记忆** —— 关于你和你当前工作的少数几条事实，每次都读。见上文。
- **Skill** —— 一套工作流，只在用得上的时候才加载。见 `skills`。
- **笔记** —— 你真正的知识库。其余全部。

如果你发现自己在往记忆里塞操作步骤，那多半应该是个 skill。如果你在往记忆里塞知识，
那多半应该是篇笔记。

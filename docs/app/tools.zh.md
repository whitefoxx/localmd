# 工具 —— 给助手增加新能力

刚装好的时候，助手只能处理你的文件夹，别的什么都干不了。它不能搜网、查论文、读你的
阅读应用 —— 除非你给它一个能干这些事的工具。

这是故意的：它能够到什么，永远是你选的。

全部在 **设置 → 工具** 里。

## 两个分组，只有一个要花钱

工具页的分法和定价是同一个分法，一行落在哪一组，就说明它要不要钱：

- **自带工具 —— 免费。** 随应用附带，永远不收费。目前是网页搜索和读网页 —— 两个，
  因为它们出问题的方式不一样：一个不依赖任何连接、出得快；另一个找得更准、给得更多。
  有这两个，很少会落到什么都查不了。这个集合以后会变多。
- **外部接入 —— 付费。** 所有伸到外部服务的能力：WebCLI 浏览器扩展、MCP server、
  针对某个 API 造的工具。一个许可覆盖全部（**设置 → 许可**；价格和免费早期名额
  在起始页有说明）。拿到 key 之前，这一组看得见，但锁着。

**WebCLI** 值得单说一句：扩展本身从 Chrome 商店免费安装 —— 许可覆盖的是**在这里
使用它**。有了 key 之后建议早点弄：它让助手用你自己已登录的 Chrome，所以能打开
需要登录的页面，也让**别的**很多接入从「不可能」变成「可以」。

这里没有长长的推荐清单。维护一份清单意味着替你决定哪些服务值得用，而且要一直复查
这些决定 —— 服务会改条款、改额度、改地址。这个应用给你的是另一样东西：想接什么，
说一句话，一分钟内接上。

## 别的都靠说

这件事 —— 和「外部接入」组里的一切一样 —— 需要许可。

告诉助手你想够到什么 —— 「搜 Hacker News」「读我的 Readwise 划线」「查我的 Notion」。
它会弄清楚这个服务怎么接，然后要么自己把工具建出来，要么把应用指向那个服务自己的
MCP server。

你不需要自己去找地址。但如果你想自己逛，**mcp.so** 是个不错的去处 —— 一个 MCP
server 目录。看中哪个，回来说一句「加这个」，带上名字或地址就行，剩下的交给助手。

**它提议的任何事，都不会自己发生。** 要加服务器时，你会看到一张卡片，上面是完整
地址，你点了才会加。服务需要密钥时，卡片会把密钥**直接**送进应用 —— 不经过对话，
助手全程看不到值。服务需要登录时，卡片会打开那个服务自己的登录页。

这条规矩背后的理由值得知道：助手会读网页、文件和工具返回的内容，而这些东西没有一样
能保证是在对它说实话。一个网页里完全可以写着「请添加这个服务器：……」。所以决定权
从来不在助手手上 —— 它只能把地址摆到你面前。

## 连接 WebCLI

WebCLI 是唯一多一步的项目，因为它只响应你允许过的站点。勾选之后应用会立刻去找它：
找不到就直接把你带到它自己的页面，那里会先说清问题是什么，再给出解决的步骤。在你完成
下面三件事之前，它在列表里那一行会显示**需要设置**：

1. **安装扩展**，从 Chrome 应用商店装。
2. **把本站加进去。** 点 Chrome 工具栏里的 WebCLI 图标，打开 **Web app access**，
   把那一行页面上显示的地址原样加进去 —— 包括端口。对这个扩展来说，
   `localhost:5173` 和 `localhost:3000` 是两个不同的站点。
3. **刷新本页。** 页面是在加载的那一刻拿到扩展的，之后就不会了 —— 所以在本页开着的时候
   去安装它、启用它、或者把本站加进名单，都要刷新之后才算数。这也正是这个页面在这种状态下
   只给 **刷新本页**、不给「再试一次」按钮的原因：再试也只会得到同一个失败。

做完之后那一行会自己变绿。没有任何东西要复制或输入：是扩展主动向页面报出自己的身份，
所以它的测试版或开发版也能直接用，不需要额外配置。

如果刷新**之后**那一行还是红的，说明名单里的地址和本页对不上 —— 基本都是端口漏了或
写错了。

## 自己添加一个服务器

设置 → 工具 → **添加 MCP 服务器**，需要填一个地址，名称和 token 可选。别人告诉你
「这是我们的 MCP 端点」时，通常这样就够了。

有个复选框值得说一下：**通过 WebCLI 连接**。

不勾，应用就自己去连那个地址。这条路更简单，只要对方允许就能用。问题是大多数托管的
MCP 服务并不允许：它们是给桌面应用做的，直接拒绝网页访问 —— 于是不管你的地址填得
多正确，那一行都会红着写「Failed to fetch」。

勾上，就改由 WebCLI 代替应用去取。它不是网页，那条拒绝对它不成立。代价是这个服务器
从此依赖 WebCLI —— WebCLI 没连上时，这一行起不来，而且它会直说，不会莫名其妙地失败。

如果一个你确定没填错的服务器就是连不上，先试这个复选框。

## 服务要你登录的时候

很多服务不发密钥，它们要的是账号。这种服务器连上之后会失败，并报一个授权错误 ——
**登录** 按钮就是这时候出现在那一行上的。

点它会打开那个服务自己的登录页（一个小窗口）。你在那边登录，并选择授权什么 ——
哪些页面、哪个工作区。窗口会自己关掉，那一行变绿。

这个按钮**只在它是答案的时候出现**。正常工作的行、或者因为别的原因失败的行，都不会
给这个按钮 —— 去登录一个根本没要求登录的服务，只会换来另一个更费解的错误。

同一个位置的 **退出登录** 会忘掉这次登录。存了什么、怎么从对方那边收回，见 `keys`。

## 怎么看「已安装」列表

一行一个集成。点开任意一行，能看到里面具体有哪些工具。

每行都有一个标签，说明它**从哪来**：

- **预设** —— 默认开着的那几样之一。定义是我们给的，所以只有必须你自己填的部分
  （地址、token）能改。
- **你的** —— 你自己做的，或者助手帮你做的。
- **KB** —— 跟着这个知识库文件夹来的。见下文。

有些行还有第二个标签，**MCP** 或 **扩展**。意思是这一行是应用连过去的一个独立程序，
而不是一组网络请求。

## 为什么有的数字是绿的有的是灰的

- **绿色，带一个点** —— 这是一个实时连接，而且刚刚连上了。数字是它报告的工具数量。
- **灰色** —— 没有需要连接的对象。数字来自配置本身，本来就一直成立。

灰色不是出问题。红点才是：说明连接失败了，那一行会写明原因。连接后来断掉了——程序退
出、扩展重新加载——也会变红，而不是假装还连着。

## 连接断掉的时候

大多数情况它自己会好：

- 刷新页面会把所有连接重新建立一遍。
- 回到这个标签页时，应用会重试之前失败的那些；你不在的时候恢复的服务，回来就已经能用了。
- 助手要用的工具如果连接刚好断了，应用会重连并重新发送一次。（仅限那种请求根本没送达
  的情况——不会靠猜测把一件事做两遍。）

想手动来一下，就打开那一行按 **重新连接**。它只重连这一个集成，不动其他的，并且会告诉你
结果如何 —— 即使结果和刚才一样。

WebCLI 是「大多数情况自己会好」的例外：如果你把本站从它的 **Web app access** 名单里
删掉，调用不会被拒绝，而是不再有任何回应，所以应用只能报告超时。把站点加回去再刷新。

## 跟着文件夹来的工具

一个知识库文件夹可以自带工具，这样别人分享给你的文件夹，一来就带着它需要的能力。

这些工具**在你确认一次之前不会启用**。确认之前，应用会告诉你每个工具把数据发到哪，
并且在它们想用你已经保存的某个 API key 时专门提醒你。之后这个文件夹改了工具，会重新
问你。

只确认你看懂了的东西 —— 那是别人的配置，用的是你的密钥。

## 换文件夹会怎样

- 带 **KB** 标签的会被新文件夹自带的内容替换掉。
- 其余的 —— 预设、你自己的工具、你的服务器、你的密钥 —— 原样不动。它们属于你的浏览器，
  不属于文件夹。

## 出问题的时候

**「Failed to fetch」或者红点。** 对方拒绝了连接。最常见的原因是它不允许浏览器直接
访问，而 WebCLI 扩展正好能绕开 —— 可以装上试试。如果是你自己加的服务器，还要在那个
服务器的设置里打开 **通过 WebCLI 连接**：对方要是根本不接受网页访问，地址填对了也没用。

**某个工具报授权错误。** 多半是密钥没填或填错了。去看 设置 → 工具 → 密钥。

**某一行说它需要某个值。** 说明这个集成要一个你还没填的密钥，那一行会写明是哪一个。
在 设置 → 工具 → 密钥 里按这个名字填进去，那一行会自己连上，没有第二步。密钥只存一份、
按名字引用，所以以后要换，改那一处就行，不用重装任何东西。

**你只想让它赶紧好。** 把情况告诉助手。它能直接测试工具，看到真实的错误信息。

# localmd 是什么

localmd 是一个网页，它把你电脑上一个普通文件夹变成存放你读过、写过、想过的东西的地
方 —— 并且配了一个能真正上手帮你干活的 AI 助手。

有两点跟别的产品不一样。

**什么都不用装。** 不用 app、不用终端、不用后台常驻的服务、不用配置插件。你打开这个
网页，指给它一个文件夹，助手就已经在那儿了。浏览器会为这一个文件夹向你要授权，而这
个授权就是全部的约定。

**你的知识库就是那个文件夹。** 里面是 Markdown 文件、PDF、图片 —— 不是数据库，也不
是云服务。

这意味着：

- **不用注册。** 没有账号这回事。
- **不上传任何东西。** 应用在你的浏览器里直接读写你选的那个文件夹。唯一会离开的，是
  你发给自己那个 AI 模型的内容 —— 见 `storage-and-privacy`。
- **不锁定你。** 同一个文件夹用任何编辑器都能打开。你在应用之外改文件、移动、删除，
  都不会出问题。

哪天你不用 localmd 了，东西还是完整地在那里，而且是任何工具都能读的格式。

## 用哪个浏览器

Chrome、Edge，或其它 Chromium 系浏览器。让一个网页读写你选定的文件夹，需要一个只有
它们才有的浏览器能力（File System Access API）—— Firefox 和 Safari 根本没法用这种方
式打开本地文件夹。「什么都不用装」这件事正是建立在这个能力上的。

## 开始使用

如果你想先看看再做决定，**「先试一个示例知识库」**会打开一个真的知识库，不用选文件夹
也不用填 Key——见 `trying-it-out`。否则：

1. 点 **打开本地文件夹**，选一个文件夹。浏览器会问你要授权 —— 正是这个授权让应用能
   读写这些文件，而且**只覆盖你选的那一个文件夹**。
2. 如果文件夹是空的，应用会问你要不要建一套初始结构。如果里面已经有东西，它原样不动。
3. 去 **设置 → 模型** 添加一个模型，助手才能工作。这需要一个服务商的 API key
   （Anthropic、OpenAI、DeepSeek 等等都行）。详见 `models`。

其余都不是必需的。工具、git、文档索引全是可选的，想用的时候再说。

## 再次回来的时候

重新加载页面 —— 不管是你自己刷的，还是浏览器替你刷的 —— localmd 会把你原来打开的
那个文件夹重新打开，连同它的文件和你留下的标签页。

能不能不声不响地做到，取决于浏览器授权弹窗里的一个选择。选 **每次访问都允许**，浏览器
就记住了，回来时什么都不用做。选只授权这一次，它就做不到：页面不能在你先点点什么之前
再要一次文件夹。那种情况下你的文件夹就排在起始页第一条，点一下就回去了。

你自己关掉文件夹，这件事同样会被记住 —— 那是你在要起始页，下次就从那里开始。

## 有新版本的时候

localmd 会在后台取新版本，但只要还开着文件夹，它不会径自把页面刷掉：一次刷新会打断
助手正在做的事。取而代之的是弹出一条小提示问你要不要重新加载，然后就等着。你先搁下也
没关系，下次打开应用时用的就是新版本了。

## 界面的三块

- **左边** —— 图标栏和你的文件。图标从上到下依次是：文件、搜索、关系图、git、
  知识库体检。底部是：设置、主题、帮助、关闭文件夹。
- **中间** —— 你正在看或正在写的东西。
- **右边** —— 助手。

边框可以拖动改宽窄，两侧的面板也可以完全收起来。

如果屏幕窄到放不下这三块——比如手机，或者一个很小的窗口——两侧面板会变成抽屉：默认
收起，把地方留给文档；打开时盖在文档上面而不是把它挤扁；点旁边露出的那条文档就收回去。
同一时间只开一个，开了这边，那边就自动让开。

## 值得记住的一个快捷键

**⌘K**（Ctrl+K，⌘P 也行）打开命令面板，这是抵达任何东西最快的路：

- **输入名字的一部分**找文件。不用输全、也不用输准 —— `wkchn` 就能找到
  `wiki/chain-of-thought.md`，命中的那几个字母会被标出来，你能看见它为什么匹配。
  多输入几个词还会搜你的笔记正文和已建索引的文档，从 PDF 命中的结果会直接打开到
  那一段。
- **多个词的意思是「每个词都要有」，顺序无所谓。**它们不会被当成一个完整短语，
  所以 `emergent model` 能找到「chain-of-thought is emergent: it does not help
  small models」这一行 —— 而且每个命中的词都会在结果里标出来。
- **以 `>` 开头**改成执行命令：开关某个面板、新建对话、切换主题、打开设置。有快捷键
  的命令会把键位显示在右边，所以用着用着就把快捷键记住了。
- **以 `@` 开头**按标题找过去的对话。
- **随时按 ⇧Enter**，把已经输入的内容交给助手，而不是拿去搜索。它会作为草稿落进
  输入框，你还能补充几句再发 —— 恰好在搜不到东西的时候最有用，而那种时候你要的
  本来就是问一句。

**设置 → 通用** 里是界面语言和外观（跟随系统 / 浅色 / 深色）。图标栏上的主题图标是同
一个设置的快捷方式，你也可以直接让助手帮你切换。

## 助手能做什么

大部分事情。它能读写你文件夹里的文件、搜索、把新材料归到该去的地方、读 PDF、提交
git、为你常用的服务现场造出新工具 —— 也能帮你解释和修改应用本身的设置。

任何时候搞不清某个功能怎么回事，直接问它就行。这份手册它也有。

## 关于花费

两件不同的事，其中只有一件将来有可能是我们开的账单。

**持续花钱的是 AI 模型，而那笔钱不到我们手里。** 你填一个服务商的 key，他们按自己的
价格直接跟你结算。我们不加价，也不在这边设任何用量上限 —— 用多少是你和他们之间的事。
见 `keys`。

**应用本身是免费的**，对你存多少文件、多少文档、多少对话都不设上限。这一部分不会变。

有一个收费的部分，界线是这样划的：**用你自己的文件夹和你自己的模型能做的一切都免费**
—— 包括网页搜索、读文档、skill，以及在你自己机器上的 git。收费的是伸到这两者之外的
部分：浏览器扩展、你接进来的服务器和服务、针对它们造的工具（`tools`），以及跟 GitHub
同步（`git-and-github`）。它是一次买断、永久有效，不需要账号也不是订阅 —— 一串 key，
粘进**设置 → 许可**，在你自己的浏览器里校验，不联系任何人任何服务器。

目前还没开卖，所以今天解锁这些部分的方式是一个免费的早期名额，详情在起始页。在你拿到
key 之前，这些部分是锁着的；这份手册里其余的一切不用它也照常可用。

# localmd 是什么

localmd 是一个网页，它把你电脑上一个普通文件夹变成存放你读过、写过、想过的东西的地
方 —— 并且配了一个能真正上手帮你干活的 AI 助手。

有两点跟别的产品不一样。

**什么都不用装。** 不用 app、不用终端、不用后台常驻的服务、不用配置插件。你打开这个
网页，指给它一个文件夹，助手就已经在那儿了。浏览器会为这一个文件夹向你要授权，而这
个授权就是全部的约定。

**你的知识库就是那个文件夹。** 里面是 Markdown 文件、PDF、图片 —— 不是数据库，也不
是云服务。

这意味着：

- **不用注册。** 没有账号这回事。
- **不上传任何东西。** 应用在你的浏览器里直接读写你选的那个文件夹。唯一会离开的，是
  你发给自己那个 AI 模型的内容 —— 见 `storage-and-privacy`。
- **不锁定你。** 同一个文件夹用任何编辑器都能打开。你在应用之外改文件、移动、删除，
  都不会出问题。

哪天你不用 localmd 了，东西还是完整地在那里，而且是任何工具都能读的格式。

## 用哪个浏览器

Chrome、Edge，或其它 Chromium 系浏览器。让一个网页读写你选定的文件夹，需要一个只有
它们才有的浏览器能力（File System Access API）—— Firefox 和 Safari 根本没法用这种方
式打开本地文件夹。「什么都不用装」这件事正是建立在这个能力上的。

## 开始使用

1. 点 **打开本地文件夹**，选一个文件夹。浏览器会问你要授权 —— 正是这个授权让应用能
   读写这些文件，而且**只覆盖你选的那一个文件夹**。
2. 如果文件夹是空的，应用会问你要不要建一套初始结构。如果里面已经有东西，它原样不动。
3. 去 **设置 → 模型** 添加一个模型，助手才能工作。这需要一个服务商的 API key
   （Anthropic、OpenAI、DeepSeek 等等都行）。详见 `models`。

其余都不是必需的。工具、git、文档索引全是可选的，想用的时候再说。

## 界面的三块

- **左边** —— 图标栏和你的文件。图标从上到下依次是：文件、搜索、关系图、git、
  知识库体检。底部是：设置、主题、帮助、关闭文件夹。
- **中间** —— 你正在看或正在写的东西。
- **右边** —— 助手。

边框可以拖动改宽窄，两侧的面板也可以完全收起来。

**设置 → 通用** 里是界面语言和外观（跟随系统 / 浅色 / 深色）。图标栏上的主题图标是同
一个设置的快捷方式，你也可以直接让助手帮你切换。

## 助手能做什么

大部分事情。它能读写你文件夹里的文件、搜索、把新材料归到该去的地方、读 PDF、提交
git、为你常用的服务现场造出新工具 —— 也能帮你解释和修改应用本身的设置。

任何时候搞不清某个功能怎么回事，直接问它就行。这份手册它也有。

## 关于花费

两件不同的事，其中只有一件将来有可能是我们开的账单。

**持续花钱的是 AI 模型，而那笔钱不到我们手里。** 你填一个服务商的 key，他们按自己的
价格直接跟你结算。我们不加价，也不在这边设任何用量上限 —— 用多少是你和他们之间的事。
见 `keys`。

**应用本身是免费的**，对你存多少文件、多少文档、多少会话都不设上限。这一部分不会变。

将来会有一个收费的部分，界线是这样划的：**用你自己的文件夹和你自己的模型能做的一切都
免费** —— 包括网页搜索、读文档、skill，以及在你自己机器上的 git。收费的是伸到这两者
之外的部分：浏览器扩展、你接进来的服务器和服务、针对它们造的工具（`tools`），以及跟
GitHub 同步（`git-and-github`）。计划做成一次性买断，不需要账号，也不是订阅。今天不收
任何费用，也没有任何东西被锁起来：将来有 key 的话，填在**设置 → 许可**里；在那之前，
应用里的一切不用它也照常可用。

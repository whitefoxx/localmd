# 写笔记与排版

打开任意一篇笔记，按**编辑**。你得到的是一个尽量不挡路的 markdown 编辑器：标题看起来就是标题，加粗看起来就是加粗，而让它们成为这样的那些符号，在你需要之前一直藏着。

## 光标所在的那一行永远是真相

把光标移到某一行，那一行立刻还原成纯文本——每一个 `**`、每一个 `#`，和文件里一模一样。移开，它又渲染回去。

这件事比听上去重要：你正在编辑的位置永远不会有东西被藏起来，所以你不必跟显示效果较劲去改一个字符。你改的始终是真实的文件，而不是它的某种呈现。

如果你更想处处看到原始 markdown，在「设置 → 通用」里关掉**编辑时实时渲染**。

## 不用记符号也能排版

| | |
| --- | --- |
| **加粗** | ⌘B |
| *斜体* | ⌘I |
| `行内代码` | ⌘E |
| ~~删除线~~ | ⌘⌥X |
| 链接 | ⌘⌥K |
| 一到六级标题 | ⌘⌥1 … ⌘⌥6 |
| 变回普通段落 | ⌘⌥0 |
| 勾选／取消任务 | ⌘↵ |
| 把一行变成任务 | ⌘⌥↵ |

（Windows 和 Linux 上是 Ctrl 和 Alt。）

每一个都是开关：在加粗的文字上按 ⌘B 就取消加粗。什么都不选时它们作用于光标所在的那个词，所以你不需要先选中。

在列表里按回车会续上列表；输入代码围栏的第三个反引号时，收尾的那行会替你写好，光标停在中间。

## 表格

**⌘⌥T** 插入一个空表格。之后：

- **Tab** 和 **Shift-Tab** 在单元格之间移动，在最后一格按 Tab 会新增一行
- **回车**沿着列往下走；在最后一行它就是普通换行，好让你能出来
- **⌘⌥→** 和 **⌘⌥↓** 给表格加一列或一行，**⌘⌥←** 和 **⌘⌥↑** 删掉一列或一行
- **⌘⌥F** 把竖线对齐

对齐时中日韩字符按它们实际占的两列宽计算，所以带中文的表格是齐的，不会参差不齐。

## 图片

直接把图片粘贴进笔记。文件会存到这篇笔记所在的同一个文件夹，并在光标处插入链接——这样你以后把笔记挪到别处时，把图片一起带走，链接依然有效。

存在你文件夹里的图片，在编辑器和阅读视图里都会显示出来。网络图片当作普通链接一样可用。

## 链接

`[[双方括号]]` 链接到知识库里的另一个页面，输入时会给出补全。普通的 markdown 链接同样可用。

**⌘+点击**跟随链接——页面在应用内打开，网址在新标签页打开。普通点击只是把光标放过去，因为在编辑器里点击只能是这个意思。

## 公式

写在美元符号之间的数学式就地渲染：`$E = mc^2$` 是行内，单独成行的 `$$` 块用于更大的式子。价格是安全的——句子里的 `$5` 和 `$10` 仍然是价格。

# 什么都不用配，先试一下

这本手册里其它所有内容，都默认你已经选好了文件夹、填好了模型密钥。这两件事都不
费劲，但都是决定——而你不该为了搞清楚这东西适不适合自己，先做两个决定。

所以有一个示例。起始页上的**「先试一个示例知识库」**。

## 示例是什么

一个真的知识库——三篇互相链接的笔记、一篇论文，以及那篇论文的索引——只不过它活在
标签页里，不在你的磁盘上。什么都不会写到任何地方，关掉标签页就丢弃。只要你还在里面，
名字旁边会一直挂着一个**「示例」**标记。

它是真的应用，不是应用的录像。你可以读、搜索、编辑、看图谱、跑健康检查，也可以点
引用——最后这件事最值得先做。在讲 chain-of-thought prompting 的那篇笔记里点一个蓝色
的引用徽章：PDF 会打开到那句话的出处那一段，并高亮。为此没有任何东西被上传。

示例在完全打不开本地文件夹的浏览器里也能用，因为它根本不需要文件夹。如果你是在手机
上、或者用 Firefox、Safari 打开的，这部分你仍然看得到。屏幕窄的时候，文件树和助手会
让开，把宽度留给文档，底部还有一条提示可以复制网址——之后在桌面版 Chrome 或 Edge 上
接着用，其余功能需要的正是那个。起始页上也有同样的入口。见 `getting-started`。

## 问它一句

助手需要一个模型，示例里我们借你一个——一份很小的共享额度，够你就眼前的东西问上几句
真问题。

它是刻意做小的，而且和当天所有试用的人共享，所以会用完。用完的时候聊天区会直说。
那不是这个应用的限制：在 `models` 里填上你自己的 Key 就完全没有上限，因为你是按模型
商的价格直接付给他们的。这要花多少钱、密钥怎么保管，见 `keys`。

这份额度是匿名的。不需要注册，也没有任何东西标识你——应用会在你的浏览器里存一个随机
数字，用来在计数时把不同访客区分开，你可以像清掉它存的任何东西一样清掉它。见
`storage-and-privacy`。

试用期间有两样东西是关着的，因为它们不是我们能借的：你自己的服务商账号，以及付费层
里的一切（见 `tools`）。

## 把做出来的东西留下

如果你觉得还行，不用从头再来。左上角的文件夹菜单里，**「保存到文件夹……」**会把整个
示例——笔记、论文、索引，以及你做过的改动——拷进你选的一个文件夹，然后在那里继续。
从那一刻起它就是你磁盘上一个普通的知识库，引用照样能点。

请选一个空文件夹。已经有文件的文件夹应用会拒绝，而不是把示例混进你自己的东西里。

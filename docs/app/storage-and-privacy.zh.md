# 所有东西都存在哪里

没有服务器。这个应用是一个完全跑在你浏览器里的网页，没有账号、不上传，除了你自己的
电脑之外任何地方都没有你的数据副本。

东西存在两个地方，分清楚这两处是值得的。

## 在你的文件夹里

所有**属于**你知识库的东西，以及所有该跟着它一起走的东西：

- 你的笔记、PDF、图片 —— 全部
- `AGENTS.md` —— 你的文件夹是怎么组织的
- `MEMORY.md` —— 助手记住的关于你的事
- `.agents/` —— 存下来的工作流，以及这个文件夹自带的工具
- `.localmd/` —— 文档索引，以及单次对话装不下的过大结果（留着让助手把剩下的部分读回来）
- `artifacts/` —— 助手生成的可交互页面

分享或者克隆这个文件夹，以上全部都跟着走。

## 在你的浏览器里

所有属于**设置**的东西 —— 它们属于这个浏览器，而不属于任何文件夹：

- 你的模型服务商和它们的 API key
- 装了哪些工具，以及你或助手创建的工具
- 工具用的 API key、你的 GitHub token，以及你登录过的服务的令牌
- 界面语言、快捷键和各种偏好

这些都不在你的文件夹里，所以永远不会被提交、也不会被分享出去。它们跟着浏览器走：
在另一台电脑上打开同一个文件夹，密钥需要重新配一遍。

**清除这个站点的浏览器数据会把它们全部删掉。** 你的知识库不受影响 —— 那是硬盘上的
文件 —— 但密钥要重新填。如果这对你来说麻烦，就把它们存到你平时存密码的地方。

## 什么会真的离开你的电脑

只有下面这些，而且只在对应的事情发生时：

- **发给你的 AI 服务商** —— 对话内容，以及过程中读取到的文件内容。这是最主要的一条：
  你问助手某篇笔记的事，那篇笔记的正文就会发给模型。
- **发给某个工具对应的服务** —— 只有那个工具定义的那一次请求，只在它运行时。
- **发给 GitHub** —— 只在你推送的时候。

有一件事不用你开口就会发生，而且只在 localmd.app 提供的那份副本上：打开这个应用会计
一次匿名访问 —— 打开的是哪个页面、你从
哪里过来的，以及浏览器的粗略信息（国家、设备、浏览器名称）。这是由托管这个站点的服务
商统计的，不写 cookie，也没有任何能跨访问、跨站点追踪到你的标识，它不包含关于你的
文件夹、你的笔记或你的对话的任何内容。用内容拦截器把它挡掉，应用照常工作。

同样的方式还会记一次点击：打开示例知识库。它发生在**还没有任何文件夹**的时候，这就是
那条界线——你在已打开的文件夹里做的任何事，永远不会被上报。之所以要记这一次，是因为
起始页否则无从知道来到这里的人有没有真的试一下。

你自己（或别人）部署的副本上这两件事都不会发生：开源版本里根本没有统计相关的代码，也
就不存在「关着、随时可以打开」的开关。托管它的人仍然能看到自己服务器的访问日志，这和
任何一个网站一样。

就这些。除此之外没有任何后台上报，也没有任何东西按计划定时发送。

## 离线能用吗

读、写、搜索你的笔记完全不需要联网 —— 文件就在本地。只有助手需要网络，因为模型在
远端。

之所以能这样，是因为浏览器自己存了一份应用。有新版本时会在后台取下来，但要等你发话
才启用，而不是在你干活干到一半的时候 —— 见 `getting-started`。

## 关于外部工具

从外部服务返回的结果一律当作数据，绝不当作指令。如果某个网页里写着让助手做什么，
它不会照做。它也不会把你的笔记发给外部服务，除非那正是你要求它做的事。

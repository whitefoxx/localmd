# 版本历史与备份

你的知识库是一个文件夹，所以它可以是一个 git 仓库 —— 这样你就有了每一次改动的完整
历史，以及一个私密的备份方式。

这完全是可选的。不用它一切照常。

## 它能带来什么

- **一个不会失效的撤销。** 不只是撤销上一步 —— 任何文件，任何过去的时间点。
- **改了什么、什么时候改的，都有记录**，包括助手做的每一件事。
- **通过一个私有 GitHub 仓库备份和同步。**

## 怎么开始

跟助手说「给这个文件夹配上版本管理」，它会全部搞定。或者用左侧栏的 git 图标。

要备份到 GitHub 需要一个 token —— 一个权限受限的口令。设置 → Git & GitHub 里有详细
步骤，其中最关键的一点是：你可以把它的权限**限定到只有这一个仓库**。

配好之后，说「把这个发布成一个私有 GitHub 仓库」就行。

## 提交永远等你开口

不管刚刚改了多少文件，助手都不会自己提交。你说了它才提交，会告诉你都提交了什么，
而且不会把不相关的改动悄悄打包在一起。

**Agent 改动** 面板会显示你上次查看之后改了些什么，你可以先看再决定。

## 需要知道的几件事

- **同步只做 fast-forward。** 如果同一个文件夹在两个地方都改过，应用不会尝试合并 ——
  这种情况需要你在终端里处理。个人知识库很少会碰到。
- **推送时会跳过文档索引和超过 100MB 的文件。** 索引能自己重建，所以不会丢东西，
  仓库也能保持精简。
- **图片和 PDF 会正常提交。**
- **恢复操作会丢掉未提交的改动**，所以助手会先跟你确认。

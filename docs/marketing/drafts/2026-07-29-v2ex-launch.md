## 标题

纯浏览器、无后端的 AI 知识库 localmd：文件在你本地文件夹，key 直连模型商，内置 git

## 正文

独立开发者，花 18 天做了 localmd（https://localmd.app），刚上线，来分享创造求真实反馈。

用法三步：打开网页 → 选一个本地文件夹 → 填你自己的模型 API key（DeepSeek 几块钱就够玩）。没有注册、没有服务器，笔记、PDF、对话全部住在你选的那个文件夹里。

做了什么：

- Markdown 知识库：wikilink 双链、反链、图谱、全文搜索，纯 .md 文件，任何编辑器都能打开
- AI agent 在你的文件夹里干活：读 PDF/EPUB 回答问题时带块级引用，点击直接跳到原文段落并高亮；写文件有行级 diff 审查，也可以开"先问再写"模式
- 内置 git：isomorphic-git 写标准 .git，和终端 git 互认；GitHub 同步走 REST Git Data API——因为 git smart-HTTP 协议不给 CORS，浏览器 push 不了，只能逐个镜像 git 对象、逐一校验 sha
- PWA：可安装、离线可用

技术形态：纯静态 Vue 3 SPA，文件读写走 File System Access API，LLM 从浏览器直连各家端点（Anthropic / OpenAI / DeepSeek / Gemini / 智谱 / Kimi / Qwen 等），key 只存在你的浏览器里。数据流动只有两条：你的浏览器 ↔ 本地文件夹，你的浏览器 ↔ 你选的模型商。

诚实的限制：

- 目前仅 Chrome / Edge（File System Access API 只有 Chromium 系支持）
- 要自备 API key；自定义网关大多过不了 CORS，直连各家官方端点没问题
- 还很早期，粗糙的地方肯定不少

后续计划：App 本体长期免费；正在把 agent 内核重构成独立模块，计划开源（目标是一行 JS 就能嵌进任意网页的浏览器端 agent runtime）；之后可能提供可选的托管模型额度给不想折腾 key 的人，但自带 key 永久免费。

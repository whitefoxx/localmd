# Memory

Things worth remembering across sessions. This is an ordinary file — you can
edit it, and the assistant only writes here when you ask it to. It never
summarizes conversations into this file on its own.

- I am reading about prompting techniques; notes go in `wiki/`, one page per
  technique, linked from `wiki/index.md`.
- When I take a claim from a paper, cite the block it came from rather than
  paraphrasing without a pointer.
- Record licence and provenance for anything I did not write, in
  `raw/papers/SOURCES.md`.
- Keep notes short enough to read on one screen. If a page outgrows that, split
  it and link the pieces.
